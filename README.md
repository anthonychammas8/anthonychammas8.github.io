## Interactive code showcase

The portfolio includes 25 selected excerpts across all 13 project areas, covering
full-stack workflows, APIs, database operations, security analysis, offline mobile
storage, real-time multiplayer synchronization, Unity gameplay, pathfinding, and
responsive front-end engineering. Excerpts are shortened and lightly cleaned for
presentation while keeping the original implementation ideas and source paths.

Visitors can search by project, feature, file path, or technology; switch between
projects and feature excerpts with mouse or keyboard controls; and copy the active
snippet. The showcase uses shortened source excerpts rather than entire files and
does not include credentials, dependencies, generated files, or private user data.
